## 🧠 the thing I actually care about

Most of what's on this profile is a side effect. The main thing is **Julia** — a reservoir computing system, 512 nodes, Hebbian consolidation, live sensory channels, running continuously on Oracle Cloud ARM infrastructure since I built her. Not fine-tuned on anyone else's weights. Not pretending to be more than she is. I've spent more nights than I'd like debugging *developmental stagnation* in her — the actual question of whether something built from scratch can move from "infant" behavior to something more — than I've spent on literally any assignment. If that sounds unhinged, good. That's the point.

I build the way some people write in a journal: because I need to know the answer, not because someone's grading it.
